Interview Prep

Concept → Example → Interview Question

Each topic pairs interview questions with a portfolio example and the quality failure mode I would test before trusting the system.

Regression

Regression Interview Questions

  • What is the difference between RMSE and MAE?
  • Why can R² be misleading?
  • When would you choose Linear Regression over Random Forest?
  • What would you check before using a regression model in production?

WPH / Portfolio Example

Regression could support translation-demand forecasting or expected time-to-English-publication after the platform has enough historical examples across countries, languages, genres, and publisher types.

Quality Angle

I would check baseline comparison, residual patterns, outliers, data drift, and whether errors are larger for specific countries or categories.

Classification

Classification Interview Questions

  • What is the difference between precision and recall?
  • Why is accuracy dangerous with imbalanced classes?
  • When would you use a confusion matrix?
  • How do you choose a classification threshold?

WPH / Portfolio Example

WPH could classify books into reader buckets, but class balance and label quality must be established before treating a classifier as reliable.

Quality Angle

I would check class balance, minority-class count, label definitions, and whether the model simply learns the majority class.

MLOps

MLOps Interview Questions

  • What is data drift?
  • What should be monitored after model release?
  • What belongs in a model card?
  • How would you decide whether to roll back a model?

WPH / Portfolio Example

Publishing activity changes over time, so recommendation or classification systems need monitoring for source freshness, feature drift, prediction changes, and confidence changes.

ML Model Validation Case Study: Residential Property Values

Outcome: Compared Linear Regression, Random Forest, and Gradient Boosting models for residential property value prediction. Random Forest performed best among the tested models with RMSE of approximately $290,919, MAE of approximately $184,569, and R² of approximately 0.517.

Model Quality Review: What I Would Test Before Production

  • Data quality: missing values, duplicates, outliers, stale records, and inconsistent fields.
  • Residual analysis: compare errors by region, price band, property type, and property age.
  • Fairness and proxy risk: evaluate whether location variables create uneven error patterns.
  • Baseline comparison: compare against simple non-ML and interpretable baselines.
  • Monitoring: track drift in features, errors, and regional market behavior.
  • Release readiness: document limitations, monitoring thresholds, rollback criteria, and intended use.
