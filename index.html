AI systems quality engineering

How I evaluate whether an AI system is ready to release

In World Publishing Houses, I connect Python regression tests, source evidence, PostgreSQL receipts, and production run diagnostics to explicit release criteria. These examples show how I investigate failures and preserve uncertainty in agent workflows.

Recover from source failures safely

Five Sweden discovery runs initially ended in a dead-letter state after remote connections closed. Following a targeted network-error repair, five sequential production runs reached human review with matching counts: 22 verified sources and three pending sources per run.

Timed-out sources remained pending after retry exhaustion. Each completed run retained a trace ID. Run-specific golden-set evidence remained an outstanding acceptance requirement at that milestone.

Test the evidence behind the decision

I reproduced a defect where changing a claim’s expected value changed its proposed verdict while leaving the evidence receipt hash unchanged. A regression test exposed the gap; the correction bound the expected value into the receipt.

The focused suite grew from nine passing tests to ten after the fix. Additional adversarial checks exposed duplicate source aliases that could falsely count as independent corroboration.

Keep verification and human approval explicit

WPH uses three terminal evidence outcomes: verified, rejected, and verification_pending. Agent proposals require human review and keep automatic promotion and trusted-path access disabled.

Acceptance covers missing provenance, conflicting evidence, fabricated receipt identifiers, replay conflicts, and Unicode differences such as Cyrillic Ё versus Latin Ë. Historical source strings remain available for inspection.

Make release confidence auditable

I assess code tests, isolated PostgreSQL checks, deployment identity, and persisted production evidence separately. Reports label checks PASS, FAIL, BLOCKED, or NOT RUN and retain the supporting run and receipt references.

These are dated engineering observations from an independent publishing-data project. End-to-end acceptance remains open wherever required evidence has not been collected.
