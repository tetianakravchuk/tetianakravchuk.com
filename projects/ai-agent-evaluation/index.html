03 / Engineering methodology
What an AI evaluator must verify
1. Schema validation
Reject malformed or structurally invalid outputs before scoring tasks.
2. Semantic completeness
Compare required tasks against extracted tasks; measure false negatives and false positives.
3. Entity correctness
Verify that action attributes and client identifiers match the intended record.
4. End-to-end checks
In a real system, confirm persisted tasks and links in APIs and databases. This lab does not claim to test persistence.
5. Failure triage
Convert missing or unsupported actions into deterministic regression fixtures.
6. Safety boundaries
Separate extracting a proposed action from executing consequential tools or financial transfers.
