What I test
Retrieval is the beginning of the check.
The engineering work is making every boundary visible and testable.

      

        
01 / Relevance
Did we retrieve the right passage?
Rank by query terms, retain document identity, and keep unrelated passages out of the final claim.

        
02 / Grounding
Does it support this exact answer?
Compare source values. A matching book title cannot establish an ISBN, translation, or licensing claim.

        
03 / Safe failure
What happens when evidence falls short?
Exclude pending sources, expose contradictions, and preserve unknowns. Human review remains a separate action.

      

      
How this relates to WPH and standard RAG
Standard RAG retrieves context and supplies it to a generative model. WPH’s documented answer layer currently uses deterministic, extractive composition with citation metadata. This browser demonstration uses keyword overlap and a small fictional corpus to make those boundaries easy to inspect.
It does not run WPH’s backend, an embedding model, vector search, live Source Checks, or model-based evaluation. Source IDs and document IDs are synthetic. Production acceptance still requires its own persisted evidence and integration checks.
