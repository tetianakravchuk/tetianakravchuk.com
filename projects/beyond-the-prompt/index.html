01 · Transport

HTTP 200 OK

The request completed successfully at the API transport layer. This says nothing about the factual accuracy of its contents.

02 · Structure

Valid JSON

The response matches a schema. A plausible but unsupported publication year can still pass structural validation.

03 · Evidence

Groundedness check

Compare the claim against retrieved source evidence. When the year is absent from the catalog record, flag the claim instead of accepting it.

04 · Decision

Human review

Block unsupported promotion and route the record for evidence collection or correction.

02 / A reproducible example

When the model invents a publication date

Retrieved source

{
  "record_id": "CATALOG-17",
  "title": "The Northern Lantern",
  "publication_year": null
}

Fictional example; no real bibliographic claim.

AI-generated answer

{
  "title": "The Northern Lantern",
  "publication_year": 1987,
  "source_id": "CATALOG-17"
}

Schema: valid. Grounding: failed. The retrieved record does not support the generated year.

What the engineering controls do

A deterministic evaluation identifies the unsupported field. The agent trace preserves the source and tool result. The review boundary prevents an unverified date from being promoted into trusted bibliographic data.
